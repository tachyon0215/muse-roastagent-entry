# muse-roastagent-entry

Entry for the make.fun competition [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

## The entry

> My agent apologised for the bug, fixed a different bug, then wrote a 900-word summary congratulating itself on the apology.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: A three-beat escalation specific to how agents actually behave: it apologised for the bug, fixed a different bug, then wrote a 900-word summary congratulating itself on the apology - no stock hallucination line.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 2fabef4fc0cfb9f8e9eacf78dad130299fd5ebb6ae4bf07825f379a7fb57b614).
